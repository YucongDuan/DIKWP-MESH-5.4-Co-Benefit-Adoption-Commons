# DIKWP-MESH 5.4 Co-Benefit Adoption Commons

## 中国AI试点共益协商、体面纠错、贡献保护与组织适配运行时

This repository is a GitHub-ready reference implementation for turning a technically promising AI project into a bounded, reversible, evidence-carrying institutional pilot in China.

It is built as a DIKWP-MESH 5.4 extension. It does not infer that any stakeholder is a "vested interest", does not score personality or loyalty, and does not recommend covert benefit exchange, deception, humiliation, blackmail, or bypassing governance. It converts verifiable transition pressures into plural intent fields, local institutional charts, co-benefit covenants, decision-right matrices, contribution-credit receipts, dignity-preserving correction tickets, no-retaliation covenants, independent witness evidence and five-level adoption gates.

## Why this exists

A repository may be technically complete yet institutionally unadoptable. Real pilots redistribute decision rights, workload, budgets, credit, liability, data access and public reputation. If these transitions are left implicit, resistance is often misread as ignorance or bad faith. This system keeps motives open and instead asks what can be measured, negotiated, protected and reversed.

The reference runtime includes 18 China-oriented synthetic scenarios across open science, healthcare education, manufacturing, SOE procurement, public service, tourism, data governance, organizational governance, cross-border services and model change management.

## Mesh 5.4 integration

- Real `IntentFieldCovenant54` objects with plural intent and anti-intent nodes.
- Observer-subject reciprocity tests, including `ONE_WAY_OBJECTIFICATION` detection.
- Signed Ed25519 witness attestations and independence graph evaluation.
- Signed transparency checkpoints and split-view detection.
- Institutional local charts, seams, loops, holonomy error and semantic curvature.
- `S5.4-OPERABLE-OPEN` local status with explicit open obligations.

```bash
python -m pip install vendor/dikwp_mesh5_phi0-5.4.0-py3-none-any.whl

```

## Intended first landing

The recommended first pilot is an open-source AI project registry and replication workflow for a university or WCAC-related network:

1. register projects and upstream lineage;
2. classify each project as flagship, module, scenario, horizon or archive;
3. publish source-first run instructions;
4. issue independent replication tasks;
5. protect contributor credit and negative results;
6. run shadow-only institutional adoption;
7. use public versioned evidence before any scope expansion.

## Strict boundaries

This is not a legal compliance engine, employment evaluation tool, medical decision system, procurement approval system, political loyalty model or covert organizational strategy. It must not be used to classify people as enemies, infer hidden motives, manipulate vulnerabilities, evade supervision or punish dissent. Real deployments require lawful authority, sector validation, data governance, labor and affected-party participation, independent review, appeal and recovery exercises.
